# Security Policy

## Supported versions

Simple is in early development. No stable release or long-term security support
policy has been announced. A supported-version matrix will be published when
versioned releases begin.

## Reporting a vulnerability

**Do not open a public GitHub issue for a security vulnerability.**

Use the repository's [private vulnerability reporting](https://github.com/hainuoli/simple/security/advisories/new)
feature to submit a report with a minimal reproduction, impact, and affected
versions or commits.

If the private reporting feature is unavailable, open a public issue **without
vulnerability details** requesting a confidential reporting channel.
Please do not publish proof-of-concept code before coordinating disclosure.

We will assess reports and coordinate a fix and disclosure where appropriate.
No guaranteed response or remediation timeframe is promised during early development.
